# Project Instructions

## Instruction Language

- Always write `AGENTS.md` files and all skill files in English, including skill metadata and supporting instructions.

## Git

Before any Git operation or commit preparation, read and apply the local [git-workflow](.agents/skills/git-workflow/SKILL.md) skill. It requires commit messages in English following Conventional Commits and explicit human confirmation for Git operations, including read-only queries. This requirement also applies to integrations and other tools.
